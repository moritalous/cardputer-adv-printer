# 印刷テンプレートの書式

印刷内容のテンプレートは `contents/print.md` に書きます。`tools/gen-content.mjs` が
これを読んで `sketch/content.h` を生成し、スケッチに埋め込みます。

**`sketch/content.h` は生成物です。直接編集しないでください**(次の `npm run gen` で消えます)。

## 書式

Markdown と名乗っていますが、**解釈するのは画像リンクだけ**です。

| 記法 | 動作 |
|---|---|
| `![alt](相対パス)` | 画像。単独行に置くこと。パスは `print.md` からの相対 |
| `{{input}}` | **キーボード入力した文字列**に置換(印刷時) |
| `{{verb}}` | `contents/verbs.txt` から**印刷ごとにランダムに 1 語**選んで置換 |
| それ以外の行 | **そのまま印字**。`#` や `**` は文字として出る |
| 空行 | 1 行分の空白として印字 |

見出しや太字は解釈しません。装飾したい場合は罫線などの文字を直接書いてください。
末尾の空行は取り除かれます。画像は何枚でも、どこにでも置けます。

```
![logo](images/sample.png)

Sample text.

Name: {{input}}
```

## 入力の埋め込み(`{{input}}`)

`{{input}}` は **Enter を押した時点のキーボード入力**に置換されます。複数箇所に
書けば同じ文字列が全部に入ります。何も入力せず Enter を押すと空文字になります
(テンプレートだけを刷る使い方も可能)。

トークンの綴りを間違えるとそのまま文字として印字されるので注意してください。
時刻トークン(`{{time}}` など)はありません(RTC 非搭載のため機能ごと廃止)。

## ランダムな動詞(`{{verb}}`)

`contents/verbs.txt` に候補を 1 行 1 語で書くと、`{{verb}}` が**印刷のたびに
ランダムな 1 語**に置換されます(Claude Code のスピナー風の演出用)。

- 空行と `#` で始まる行は無視、非 ASCII 行はビルド時に捨てられます
- 一覧はビルド時に埋め込まれるので、`verbs.txt` を変えたら `npm run flash`
- `{{verb}}` を使っているのに候補が 1 つも無い場合は `npm run gen` が止まります
- サンプルは `contents/verbs.txt.example`(コピーして使う)

## 画像の扱い

PNG と JPEG を受け付けます。**幅 384px が上限**です(用紙の印字幅 464px から
左右マージン 40px ×2 を引いた値)。

| 元のサイズ | 結果 |
|---|---|
| 幅 384px 超 | アスペクト比を保って幅 384px に縮小 |
| 幅 384px 以下 | **そのまま**。拡大はしない。384px の領域に中央寄せ |

高さに制限はありませんが、キャンバス全体(テンプレート+入力の折り返し分)が
2000px を超えると実機が `Content too tall` を表示して印刷を拒否します。

> 内部形式は PNG ではなく 1bpp パック済みビットマップとして埋め込まれます
> (理由は [design.md](design.md))。ユーザー側で意識することはありません。

## 階調モード

画像は生成時に白黒 2 値へ変換します。モードは `package.json` の `gen` スクリプトで指定します。

| `--mode` | 意味 | 向き |
|---|---|---|
| `standard` | Bayer 8×8 の組織的ディザ | 既定。規則的な網掛け |
| `grayscale` | Floyd-Steinberg 誤差拡散 | 写真。階調が滑らか |
| `mono` | しきい値のみ | ロゴ・線画・文字。輪郭がシャープ |

刷り比べて決めてください。変更後は `npm run flash` で反映します。

## フォントの制約

M5GFX の `lgfxJapanGothic_20`(IPA ゴシック由来)で描画します。テンプレートには
日本語を書けます(キーボード入力は ASCII のみ)。**収録は JIS X 0208 系の部分集合
(0x100 以上で 3,306 文字)**なので、入っていない文字は □ になります。

| 文字 | 収録 |
|---|---|
| ▲ △ ▼ ▽ | ○ |
| ≫ 》〉→ ⇒ ＞ ● ◆ ■ ━ ┃ | ○ |
| ⏵ / ▶ / ▷ / ► / ➤ | **✕ 右向きの三角はすべて未収録** |

上下の三角はあるのに左右が無いのは JIS X 0208 の構成によるものです。`▶` に
置き換えても直らないので、`≫` などの収録済み文字を使ってください。

太字・斜体のフォントは日本語には存在しません(`FreeSansBold` などは Latin 専用で、
日本語と混植すると字形が破綻します)。

## 折り返し

長い行は用紙幅 464px で折り返します。**1 行あたり全角 21 文字が上限**です。
`{{input}}` に長い文字列を入れた場合も同様に折り返されます。折り返した続きの行は
左マージンに揃いません。
